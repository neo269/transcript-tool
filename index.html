Transcript Extractor

Turn a Paper2Audio JSON into clean, readable text with section headings.

Step 1 · Get the JSON from the app

Copy the response out of your browser

  1. Open the Paper2Audio page with the summary you want.
  2. Press F12 (or right-click → Inspect) to open Developer Tools.
  3. Click the Network tab at the top.
  4. Reload the page with F5 so it captures the requests.
  5. Click the search icon (🔍, next to the red circle) and type a distinctive word from the transcript.
  6. Click the result — it jumps to a request named like AuthorName-BookTitle-…
  7. Right-click that request → Copy → Copy response.
Can't find it by search? Click the Fetch/XHR filter, then check each request's Preview tab for one full of readable words. If “Copy response” misbehaves, use Save all as HAR and open that file below instead.

Backup · No install, no AI

Do it manually with jqplay

If this page ever isn't handy, you can extract the text yourself at play.jqlang.org. You'll get the raw transcript this way (headings not woven in), but it's quick and runs without any tools.

  1. Open play.jqlang.org.
  2. Paste your JSON into the JSON box (bottom-left).
  3. In the Query box (top-left), type: [.segments[].transcript] | join("\n\n")
  4. Open the Options dropdown and turn on raw output (-r) so quotes and \n become real line breaks.
  5. Copy the clean text from the Output box on the right.
Want the section titles too? Run a second query — .tableOfContents[].transcript — to list all the headings, though you'd have to slot them in by hand. For headings already in place, use this page above instead.
